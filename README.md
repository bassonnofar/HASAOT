המערכת בנויה משני חלקים:
- **`Code.gs`**: השרת. רץ ב-Google Apps Script, קורא את טבלת ההסעות של המדריכים ושומר את הנתונים בקובץ נפרד.
- **`index.html`** ושאר הקבצים: הממשק. יושב ב-GitHub Pages.

| כתובת | למי |
|---|---|
| `https://bassonnofar.github.io/hasaot/` | החניכים: הרשמה, התחנה שלי ומסך האחראי/ת |

## התקנה (פעם אחת, בערך 15 דקות)

### שלב 1: השרת ב-Apps Script
1. נכנסים ל-script.google.com מ**החשבון שיש לו גישה לקובץ "הסעות תשפ"ז"**, ולוחצים **New project**.
2. מוחקים את מה שכתוב בעורך ומדביקים את כל התוכן של `Code.gs`.
3. בראש הקובץ, בתוך `SETUP`, ממלאים:
   - `OWNER_PHONE`: הטלפון שלך
   - `OWNER_PIN`: קוד כניסה של 4 עד 8 ספרות
4. שומרים (Ctrl+S), בוחרים בסרגל העליון את הפונקציה **`setup`** ולוחצים **Run**.
   מאשרים את ההרשאות: Review permissions ← בוחרים את החשבון ← Advanced ← Go to project ← Allow.
5. ביומן (Execution log) צריכה להופיע ההודעה "ההתקנה הושלמה". בשלב הזה נוצר בדרייב שלך קובץ בשם **"מערכת הסעות — נתונים"**. לא עורכים אותו ידנית.
6. **Deploy ← New deployment**, ובגלגל השיניים בוחרים **Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
   - לוחצים Deploy ומעתיקים את הכתובת (Web app URL), שנגמרת ב-`/exec`.

### שלב 2: הממשק ב-GitHub
1. פותחים את `index.html` ומחליפים את `PASTE_APPS_SCRIPT_URL_HERE` בכתובת שהעתקת:
   ```js
   const API_URL = 'https://script.google.com/macros/s/....../exec';
   ```
2. ב-GitHub יוצרים repository חדש בשם `hasaot` (Public).
3. Add file ← Upload files, ומעלים: `index.html`, `manifest.json`, `icon.svg`, `icon-192.png`, `icon-512.png`.
4. Settings ← Pages ← Branch: `main` ← Save. אחרי דקה-שתיים האתר עולה.

### שלב 3: בדיקה
1. נכנסים ל-`.../hasaot/#admin` עם הטלפון והקוד שהגדרת.
2. בטאב **ניהול ← צוות** מוסיפים מנהלים תורנים (שם, טלפון, קוד). לכל אחד שולחים את הקישור `#admin` ואת הקוד שלו.
3. בטאב **ניהול ← תחנות** כותבים לכל תחנה איפה בדיוק מחכים, ומדביקים קישור לגוגל מפות.
4. את הקישור לחניכים (בלי `#admin`) שולחים בקבוצות הוואטסאפ של הקבוצות.

> **עדכון קוד בעתיד:** ב-Apps Script עושים Deploy ← Manage deployments ← ✏️ ← Version: New version ← Deploy. ככה הכתובת נשארת אותה כתובת. אם יוצרים New deployment, נוצרת כתובת חדשה, וצריך לעדכן אותה ב-index.html.

## איך זה עובד במוצ"ש

**המנהל/ת התורן/ית:**
1. **משמרת ← פתיחת יום הסעות**: המערכת מוצאת לבד את הגיליון שמתחיל ב"חזור" ומציגה מה היא קראה. בודקים ומאשרים.
2. בכל קו: **⚙️ הגדרת קו** ← מזינים את פרטי הנהג מהסדרן ובוחרים חניך/ה אחראי/ת ומחליף/ה ← **שמירה ושליחה לנהג**. נפתח וואטסאפ עם רשימת התחנות והשמות, ונשאר רק ללחוץ שליחה.
3. **💬 לאחראי/ת**: שולחים לאחראי/ת הודעה עם הוראות.
4. במהלך הנסיעה עוקבים אחרי **"דורש טיפול"**: מי לא עלה, מי מאחר, קו בלי מיקום וכו'. יש כפתור 📞 לכל חניך.
5. בסוף: **סגירת יום**. הסטטוסים נשמרים להיסטוריה, ומתקבל סיכום לשליחה בוואטסאפ.

**החניך/ה האחראי/ת:** "למסך האחראי/ת" ← הפעלת שיתוף מיקום ← בכל תחנה מסמנים ✓ או ✗ ← "יצאנו" ← בסוף "הגענו לכפר".

**חניכים:** רואים את התחנה, השעה, איפה לחכות ואיפה ההסעה עכשיו. מדווחים "אני בתחנה", "אני מאחר/ת" או "לא נוסע/ת", ויכולים להתקשר לאחראי/ת אם הוא/היא הסכים/ה להציג את המספר.

- **הנהג/ת** לא רואה אף מספר של חניך. הוא/היא מקבל/ת רק שמות פרטיים.
- **חניכים** רואים רק את המספר של החניך/ה האחראי/ת בקו שלהם, ורק אם הוא/היא סימן/ה הסכמה בהרשמה.
- **הטלפון של הנהג/ת** מוצג רק לאחראי/ת ולצוות.

## איך המערכת קוראת את הטבלה
- כל קו הוא בלוק. השם שלו בעמודה A, ובתוך הבלוק יש שורה של שמות תחנות, ומתחתיה שורה של שעות.
- מתחת לכל תחנה כותבים חניכים בפורמט **"שם - קבוצה"**, למשל `יואל - אלמוג`.
- אם יש שני חניכים עם אותו שם באותה קבוצה, כדאי להוסיף אות משם המשפחה: `דניאל ל - ענר`.
- חניכים שנוספים לטבלה אחרי פתיחת היום מופיעים במערכת תוך חצי דקה, עם סימון "חדש".
- **חשוב:** כדי שחניך יזוהה גם בשבוע הבא, השם שלו צריך להיכתב בכל שבוע באותה צורה.
